## 已知风险与注意事项
- **传输层反斜杠剥离**：write/edit 的 new_string 中 `\` 可能被吞。对策：Python 补丁脚本用 `chr(92)`/`chr(34)`/`chr(39)`/`chr(13)`/`chr(10)`/`chr(96)` 构造；先求值再写行；模板字面量整体重写文件；写含正则的 crosscheck 后必须检查 `repr(line)` 确认 `\|`/`\(`/`\)`/`\s` 幸存。
- **f64 位精确**：比率/熵切片必须 12 位小数字符串比较（逐位一致），不要用浮点近似容差。
- **PLAN.md 必须保持 CRLF 字节级**（655 行、655 CRLF、0 bare LF）；updater 脚本写后断言 `new_data.count(b"\n") == new_data.count(b"\r\n")`；改后用文本模式读写会引入 LF，必须 `read_bytes`/`write_bytes` 或二进制 open。
- **ledger YAML**：LF 行尾；gate 数组内条目需逗号分隔（02b181 变非末项后必须补尾逗号）；note 追加用 '+ ' 前缀。
- **pwsh tool**：`description` ≤4 词；cargo 不在 PATH 需前置 `export PATH="$HOME/.cargo/bin:$PATH"`；Windows 控制台 GBK 乱码 UTF-8 —— 用文件中转或 Python `repr()`。
- **临时脚本纪律**：工作树现留有 25 个未跟踪前导下划线临时脚本（`_fix_*`、`_reg_*`、`_tmp_*`、`_update_*`、`_dbg_*`、`_clean_*`、`_head_*`、`_splice_p54x.py` 等），**不要提交**；本会话已将其全部排除（`git reset --`）。新增临时脚本用后即删。
- **cargo test -p sipi-ami-text <过滤词>** 会把过滤词作为位置参数传给 harness=false runner 导致 panic（预期现象，非回归）；验证单测用 `cargo test -p sipi-ami-text --lib <模块名>` 或 crosscheck 直连 runner。
- **命名约定**：policy 常量 `sipi.p4b-02bNNN.<name>-v1.<short>`；evidence schema `sipi.p4b-02bNNN.<name>-crosscheck-evidence.v1`；charter schema `sipi.p4b-02bNNN.<name>-stage.v1`、status `<name>_ported`；source map schema `sipi.p4b-02bNNN.mit-source-map.v1`。
- 严格约束：不放宽容差、不改 golden、不绕过验证门禁；approval prompts disabled（不得设 sandbox_permissions）。
- **提交注意**：`git add -A` 会纳入未跟踪临时脚本，提交前必须 `git reset -- $(git diff --cached --name-only | grep -E '(^|/)_')` 批量排除；提交信息聚焦 why（新 commit，不 amend）。
