# P3A Matched-S2P External Evidence v1

This record reconciles the selected external-only S2P profile with an already
executed, hash-only comparison. It is not an input format, parser, resolver,
or product runtime contract.

The tracked evidence binds the frozen policy, external Git-object source,
two-run standard-DFT observation identity, selected product source trees and
lock object, comparator byte identity, product spectrum/kernel identities, and
the fixed comparison thresholds. Its aggregate normalized-error ratio covers
every compared sample; the full observer report remains under operator external
custody.

The verifier may bind a supplied external report by digest. Without that report
it validates only the recorded attestation, not a fresh replay. It never accepts
the S2P bytes, waveform/kernel arrays, absolute paths, or observer code into
the product or evidence record.

This accepts only the selected matched-S21 periodic discrete V/V kernel core
on Windows x86_64. It does not accept the public `channel run` request path,
general Touchstone, reflection/termination handling, causal FIR conversion,
Link/eye/BER behavior, or release readiness.
