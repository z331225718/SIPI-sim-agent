# P3C External ADS Reference Metric Observation Evidence v1

This evidence binds two fresh external candidate executions to the immutable ADS
canonical payload and the existing sealed-artifact metric CLI. A CLI contract
rejection is an observed outcome only when both fresh runs return exit code 3.
Other CLI failures, custody failures, and cleanup failures retain no report.

The report retains no paths, waveform bytes, arrays, or CLI diagnostic streams.
It does not establish a metric value, receiver acceptance, physical causality,
AMI/P5 behavior, or release readiness.
