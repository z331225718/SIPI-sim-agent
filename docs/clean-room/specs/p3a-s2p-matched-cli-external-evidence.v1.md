# P3A Matched-S2P CLI External Evidence v1

This observer-only gate binds the selected external S2P Git object to the
bounded `sipi channel run --stdin` path. It materializes the source twice in
fresh temporary custody, requires identical independent standard-DFT kernel
identities, clean-builds `sipi-cli` from an immutable product commit, and sends
only JSON-escaped inline text to the CLI.

The response must be one LF-terminated JSON envelope with zero stderr, the
fixed matched-kernel metadata, finite 400-sample gain data, and the unchanged
`caller_input_unattested` runtime label. The observer compares each sample
against the frozen tolerance and retains only hashes, bounded metadata, and
metrics in external custody.

The tracked evidence is a hash-only attestation. Supplying the external report
to its verifier binds a fresh report; without it, the verifier does not claim a
fresh replay. No S2P bytes, response array, absolute path, PyBERT code, or
external runtime asset enters the product.

This is profile-specific CLI evidence, not general Touchstone support,
reflection or termination handling, causal-FIR or Link behavior, artifact
provenance, eye/BER behavior, or release readiness.
