## 风险与注意事项（历史踩坑，务必遵守）
- **updater 必须二进制模式 + CRLF 感知**：`read_bytes`/`write_bytes`；插入叙事时 `line_end` 必须定位到 `\r\n` **之后**（`data.index(b"\r\n", idx) + 2`），否则插入的 `\r\n` 前缀会与原行尾残留 `\r` 融合成 `\r\r\n`（round 241 首版即踩坑，产生孤立 CR + bare LF，git diff 全文件误报）。
- **ledger 是 CRLF**：匹配 gate 尾部 anchor 时必须用 `\r\n`（round 241 首版用 `\n` 匹配失败）。coverage 工具（.py）是 LF，anchor 用 `\n`。
- 插入前断言 anchor 唯一（`data.count(anchor) == 1`）且目标叙事不存在（`count == 0`），避免重复插入。
- 命名约定：charter/evidence schema 用连字符 `sipi.p4b-02bNNN-parameter-...`；policy 常量用点号 `sipi.p4b-02bNNN.parameter-...`。
- ledger 是 JSON（非 YAML），note 追加需修改 P4B-02 item 的 "note" 字段值，不能在文件末尾追加行。
- Cargo.toml 追加 `[[test]]` 前用 `tail -c 50 | od -c` 确认尾部换行，避免 `harness = false[[test]]` 粘连。
