## Method

Implement `bus_label_declaration_v1.rs` in `sipi-ibis`: `TypedBusLabelDeclarationV1`
holds a validated ASCII bus label name (`[A-Za-z0-9_.-]+`) and a list of member pin names (`member_pins`).
`lift_bus_label_declaration_v1` validates inputs and returns `Result<TypedBusLabelDeclarationV1, BusLabelDeclarationErrorV1>`.
Fail-closed: empty bus label names (`EmptyBusLabelName`), non-ASCII characters (`NonAsciiName`),
invalid name spellings (`InvalidName`), empty member pin lists (`EmptyMemberPins`), or duplicate member pins (`DuplicateMemberPin`)
are strictly rejected. An independent Python reference recomputes lifting rules over 3 test cases.
