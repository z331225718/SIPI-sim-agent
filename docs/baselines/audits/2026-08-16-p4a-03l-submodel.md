## Method

Implement `submodel_declaration_v1.rs` in `sipi-ibis`: `TypedSubmodelDeclarationV1`
holds a validated ASCII submodel name (`[A-Za-z0-9_.-]+`), Submodel_type (`Dynamic_clamp`,
`Bus_hold`, `Fall_clamp`, `Rise_clamp`), and Submodel mode (`Driving`, `Non-Driving`, `All`).
`TypedAddSubmodelV1` holds a submodel name and mode reference.
`lift_submodel_declaration_v1` and `lift_add_submodel_v1` validate inputs and return typed structures.
Fail-closed: empty submodel names (`EmptyName`), non-ASCII characters (`NonAsciiName`), invalid name
spellings (`InvalidName`), unknown Submodel_type (`UnknownSubmodelType`), or unknown Submodel mode (`UnknownSubmodelMode`)
are strictly rejected. An independent Python reference recomputes lifting rules over 3 test cases.
