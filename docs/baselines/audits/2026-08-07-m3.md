## M3 收尾-3b（publish-crash 恢复）

- `packages/sipi-runtime/src/sipi_runtime/driver.py`：两条 publish 路径（缓存命中 + 正常执行）统一为 staged 顺序——attempt → `publishing` → 落盘 `success-manifest.json` → SQLite `attempt_publish_cas` commit；写盘字节与 sha 同源，commit 后无缺失窗口。
