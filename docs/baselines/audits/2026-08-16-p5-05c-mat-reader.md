## 语义要点（与源逐点对照，均经 fixture 实测确认）

- 128 字节头（`MATLAB 5.0 MAT-file`）+ typed 元素流
- **small data element tag**：数据 ≤4 字节时打包 `(byte_count<<16)|mdtype`
  于一个 u32 + 固定 4 字节数据槽（scipy `write_smalldata_element`）；
  高 16 位非零即 small，否则 full tag（u32 mdtype + u32 byte_count + pad）
- miCOMPRESSED（zlib）解压后继续解析元素流
- matrix flags：**class 词含 logical 位 0x200**（scipy 写入行为，class=521
  实测）；dims 为 miINT32 序列；name 为 miINT8
- 字符串 cell：**scipy 用 miUTF8=16 写 ASCII 载荷**（非 UTF-16，实测确认）；
  UTF-16 载荷（miUTF16=17/miUINT16）也支持
- `_matlab_cell_value`：size0→None；size1→标量（整数→Integer、浮点→Number、
  **logical→Integer**（loadmat 返回 uint8 → `.item()` 为 int，实测））；
  字符→String 拼接；多元素数值→`Array { dims, data }` 且 **C 序展平**
  （MATLAB 列主序载荷经转置映射，2×2 非对称矩阵用例验证）
- 嵌套 cell、struct/sparse/object、复数、MAT v4/v7.3(HDF5) → fail-closed 拒绝
