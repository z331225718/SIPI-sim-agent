## 语义要点（与源逐点对照）

- C2M UI 网格重采样：`old_time` 归零到 cursor，`matlab_colon` 双向负/正
  网格拼接（去重 0），`interp1_linear`（np.interp 语义，越界 NaN 报
  R480-C2M-INTERP-RANGE）；`cursor = argmin(|new_time|)`
- DFE 消除：tap UI 索引、`dfe_step` 量化 floor 幅值 + sign、clip_dfe（复用
  04k）；`cancel_start = cursor - center_of_ui + samples_for_c2m`（实测修正
  初版 +C2M 偏移）；cursor UI 区间清零；nui>=3 支撑校验
- **列主序 reshape+转置**：`matlab_reshape(v,(C2M,nui-2)).T` =
  `out[c][r] = v[c*C2M+r]`（初版索引写反导致残差近常数；双端电子眼漂移捕获并修正）
- 逐相位：`sampled_signal_pdf_v1`（复用 04f）、gaussian=std(σ_rj·σ_X·‖h_J‖, σ_n, σ_tx)
  ⊗ ne、dual-dirac=`sampled_signal_pdf(A_DD·h_J)` 卷积；`_signal_level_pdf_data` 共享
  概率 + 逐 symbol MATLAB 舍入 origin；**avsig 按绝对相位索引 `available_signal[phase]`**
  （初版误用 phase_position 捕获并修正）
- 缩减：`_histogram_weights`（rectangle/gaussian/triangle/dual_rayleigh）、
  `_weighted_sum_shared_integer_axis`（整数 origin 对齐）、`ber_contour`（**高尾
  从高电压端扫描**；初版对反转后 cumsum 从前端扫描取到最大 bin 修正）、
  worst 相邻层眼（argmin 高度；初版误用 argmax 修正）
- 非法控制 / PDF bin 不匹配 / T_O 越界 / DFE span / 零 cursor / BER 范围 → fail-closed
