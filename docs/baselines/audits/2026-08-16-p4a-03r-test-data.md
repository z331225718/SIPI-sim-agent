## Method

Implement `test_data_declaration_v1.rs` in `sipi-ibis`: `TypedTestDataDeclarationV1`
holds a validated ASCII fixture name (`[A-Za-z0-9_.-]+`), optional `r_fixture_ohm`,
`c_fixture_farad`, `l_fixture_henry`, and `v_fixture_volts`.
`lift_test_data_declaration_v1` validates inputs and returns `Result<TypedTestDataDeclarationV1, TestDataDeclarationErrorV1>`.
Fail-closed: empty fixture names (`EmptyFixtureName`), non-ASCII characters (`NonAsciiFixtureName`),
invalid name spellings (`InvalidFixtureName`), non-finite values (`NonFiniteValue`), or negative
R/C/L fixture values (`NegativeFixtureParameter`) are strictly rejected.
An independent Python reference recomputes lifting rules over 3 test cases.
