## Method

Implement `diff_pin_declaration_v1.rs` in `sipi-ibis`: `TypedDiffPinDeclarationV1`
holds validated non-inverting (`pin_non_inv`) and inverting (`pin_inv`) ASCII pin names,
optional differential threshold voltage (`vdiff_v`), and optional differential delay (`tdelay_s`).
`.lift_diff_pin_declaration_v1` validates inputs and returns `Result<TypedDiffPinDeclarationV1, DiffPinDeclarationErrorV1>`.
Fail-closed: empty pin names (`EmptyPinName`), non-ASCII characters (`NonAsciiPinName`), identical pin pairs (`IdenticalPins`),
non-finite values (`NonFiniteValue`), or negative threshold/delay values (`NegativeThreshold`) are strictly rejected.
An independent Python reference recomputes lifting rules over 3 test cases.
