# P7-09a External History Citation Boundary

The P7 publication scope now permits only hash-only citations registered in
`external-history-citations.v1.yaml`. The renderer-facing index carries the
alias and full immutable hash marker, never a local workspace path, historical
source path, branch, tag, or asset bytes.

This is a release-document boundary only. It neither removes the repository's
existing migration/oracle material nor decides any third-party license or
clean-room legal question. Promotion remains blocked.
