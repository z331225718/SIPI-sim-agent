## 语义要点（与源逐点对照）

- apply：`output[i] = Σ_k c_k · values[(i − (k−pc)·spu) mod n]`（np.roll 回绕
  语义，零系数跳过；pc 必须标识 cursor tap）
- force：直接求解矩阵 `matrix[o][i] = values[cursor + (o−i)·spu]`（越界零）、
  forcing[pc] = values[cursor]、dfe_first_max 时 postcursor 截断 forcing[pc+1]
- **LU 求解器**：自实现 partial-pivot LU（零 pivot → 奇异，对应
  LinAlgError）；与 LAPACK dgesv **数学等价但非位级一致**（crosscheck
  容差 1e-9 记录于证据，非放宽）
- unity_cursor：taps /= taps[pc]（零 → `ZERO-CURSOR` 拒绝）；tap_step：
  floor 幅值量化
