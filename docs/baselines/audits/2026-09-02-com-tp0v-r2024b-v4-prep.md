## Comparison contract

The current TP0V profile compares the ordered scalar surface for the selected
package case (case index `0`) with the existing `1e-9` finite absolute
tolerance. The trace source proves package testcase index `0` only. Its two
entries are physical ports 1 and 2, not two package cases; therefore v4 binds
the one selected package case to port 1 and does not copy port 2 into case 1.
Vector comparison is one-dimensional, element-by-element, with exact shape,
order, count, first-sample presence, finite values, and strictly increasing
`time_s`. The only tolerances are:

| Vector | Absolute | Relative | Unit |
| --- | ---: | ---: | --- |
| `time_s` | `5e-24` | `0` | s |
| `impedance_ohm` | `2e-12` | `2e-14` | ohm |
| `ptdr` | `5e-17` | `2e-14` | linear |
| `gated` | `5e-17` | `2e-14` | linear |

The limit is `absolute + relative * abs(reference)`. No alignment,
resampling, interpolation, truncation, or delay correction is permitted.
Each engine must reproduce its own payload exactly on the second repeat before
cross-engine comparison is considered.
