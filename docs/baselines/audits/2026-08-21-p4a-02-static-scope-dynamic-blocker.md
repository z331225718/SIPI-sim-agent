# P4A-02 Static Scope and Dynamic Blocker

## Closed Scope

The authorized Gen5 material contributes only a hash-bound behavior-spec
observation: TX probes were observed and the RX probe crashed on every recorded
case. It does not define parser, interpolation, clamp, package, PVT, terminal,
or AMI runtime semantics and is not numerical acceptance.

The product's existing static/declaration scope is separately and exactly
bounded by the P4A IBIS conformance matrix and the P4A-03 complete-document
typed inventory consumer. Those records close inventory and already-admitted
static/declaration primitives only; they do not turn the Gen5 observation into
a product implementation or accepted profile.

## Independent Dynamic Blocker

A dynamic endpoint cannot be implemented without guessing. The composition
contract still blocks terminal/reference mapping, supply, initial state,
integration method, internal timebase and output grid, channel return and
stimulus, numeric resource bounds, dynamic tolerances, and acceptance evidence.
P4A-T12 therefore remains an independent external decision/evidence blocker.

No quasi-static or batch route is transient evidence. This split makes the
bounded static/declaration scope closeable without claiming general IBIS,
transient parity, AMI runtime, external profile acceptance, or release
promotion.
