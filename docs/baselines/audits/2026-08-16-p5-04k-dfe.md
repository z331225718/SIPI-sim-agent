## 语义要点（与源逐点对照）

- tail-RSS：`tail = taps[start:]`、`rss = ‖tail‖`；`rss && rss >= rss_max`
  时 magnitude = min(rss, rss_max)·|tail|/rss 重写 upper/lower；None 起点
  （源零值）→ rss 0.0 原样返回
- clip：元素级 min(upper, max(lower, v))；size/顺序校验
- findbankloc：window = |hisi[start..=end]|、reduced 按 cursor 符号归零、
  energy = sliding(window) − sliding(reduced)、**stable 降序 argsort**、
  首 bank 前缀有序特例提前返回、overlap 拒绝（bad 过滤已选、good 候选、
  energy[bad]=-inf）、`-1` 哨兵规避零基端点歧义、最终 sort + start 偏移
- applyDFEbk：量化 `floor(|v/cursor|/qs)·qs·sign·cursor`（**floor 幅值截断**
  与 MATLAB 一致）、coeff = min(|q/cursor|, cl)·sign、residual 改写、
  reference 归零；cursor==0 / 越界 / 负控制 → fail-closed
