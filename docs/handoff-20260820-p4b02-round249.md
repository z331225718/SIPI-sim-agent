## What was audited

- Compared the repository after `b70f8c6` through the current worktree, including the large P4A/P4B/P5/P7 batches added by several agents.
- Inspected PLAN/ledger coverage, Cargo target registration, P4B evidence/runner identity, public Rust reachability, parser data-loss paths, capacity limits, workspace formatting/lints/tests, and P0 publication/license boundaries.
- Removed tracked simulator leftovers: `ffecoeffout.txt`, `log_objects_init.csv`, and `simDone.txt`.

## High-impact findings

1. The old open-item coverage gate counted hard-coded file existence. It did not derive items from PLAN/ledger, require tracked gates, or execute them.
2. 191 P4B-02b reports said `matched_hash_bound` without source, runner, or independent-reference digests. They were product Rust compared with product-owned Python logic, not external evidence.
3. The 191 `harness=false` runners were registered as Cargo tests. No-argument execution commonly printed usage and exited successfully, so `cargo test` did not prove crosscheck execution.
4. `parameter_trees_v1` silently discarded scalar/quoted siblings whenever a node also contained a sublist.
5. The parameter list/tree/profile surface had no uniform size/work budget and 193 exported modules had no production Rust consumer outside `sipi-ami-text`.
6. Full-workspace tests exposed a feature-unification bug: an unused `serde_json/arbitrary_precision` dev feature in `sipi-com` changed JSON number deserialization for unrelated crates.
7. Several publication and micro-slice verifiers had stale digests, formatting-sensitive source tokens, or copy/paste policy bindings.
8. PLAN had interleaved checklist records and lines over 100k characters, making review and regex gates unreliable.

## Fixes in this commit

- Coverage verifier v2 derives 28 open IDs from PLAN and the remaining-items ledger, requires tracked verifier paths, and reports `executed_gates=0` instead of claiming execution.
- All affected P4B evidence is reclassified as `product_owned_self_crosscheck_unbound`; no external/profile/release gate is promoted.
- P4B-02b194..196 uncommitted expansion was withdrawn. The existing 193 modules are available only to tests or explicit `p4b-self-crosscheck`; default host/worker product dependencies cannot consume them.
- One feature-gated, `test=false` dispatcher replaces 191 Cargo test targets. Historical runner sources remain callable by the dispatcher, but no-argument Cargo tests no longer count as evidence.
- Mixed scalar/sublist tree content now rejects with `MixedNodeContent` instead of losing data.
- Parameter construction fixes bounded name/value/List sizes and pair-work. Oversize, malformed, mixed-content, depth, and capacity paths fail closed.
- All external `harness=false` binaries are marked `test=false`; observers must build/invoke them explicitly.
- Removed the unused `serde_json/arbitrary_precision` feature that broke workspace-wide JSON tests.
- Fixed workspace lint defects and brittle verifier bindings found by full clippy/test runs.
- Publication now marks current TRAN v4 and Channel v8 external comparisons as source-drifted after the product changes. Historical files remain untouched.
- PLAN is readable again, keeps short historical verifier anchors, and contains a prioritized ten-slice continuation list.
