## 已知风险与注意事项
- **传输层反斜杠剥离**：Python 补丁脚本用 chr(92)/chr(34)/chr(39)/chr(13)/chr(10)/chr(96) 构造；写含正则的 crosscheck 后必须 repr 验证 `\\|`/`\\(`/`\\)`/`\\s` 幸存。
- **PLAN.md 必须保持 CRLF 字节级**（655 行、655 CRLF、0 bare LF）；ledger 同 CRLF（525 行）；改后二进制断言 `count(b"\\n") == count(b"\\r\\n")`。
- **ledger YAML**：gate 数组内条目逗号分隔（新增非末项时必须补尾逗号）；note 追加用 '+ ' 前缀。
- **Cargo.toml 尾部陷阱**：追加 [[test]] 前先 `tail -c n | od -c` 确认末尾换行形态，避免粘连。
- **pwsh tool**：description ≤ 4 词；cargo 不在 PATH 需前置 `export PATH="$HOME/.cargo/bin:$PATH"`；UTF-8 输出用文件中转再 read。
- **cargo test -p sipi-ami-text <过滤词>** 会把过滤词作为位置参数传给 harness=false runner 导致 panic（预期现象，非回归）；验证单测用 `cargo test -p sipi-ami-text --lib <模块名>`。
- **临时脚本纪律**：新增临时脚本（`_mk*_governance.py`、`_update*_ami.py` 等）用后即删；工作树遗留的 25 个前导下划线脚本不要提交。
- 严格约束：不放宽容差、不改 golden、不绕过验证门禁；approval prompts disabled（不得设 sandbox_permissions）。
- **提交注意**：`git add -A` 会纳入未跟踪临时脚本，提交前必须 `git reset -- $(git diff --cached --name-only | grep -E '(^|/)_')` 批量排除；提交信息聚焦 why（新 commit，不 amend）。
