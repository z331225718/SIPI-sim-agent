补充验证

IdEM S19 自适应调优

在 19 端口数据上，IdEM 的 `stagnation-alpha0p01` 配置以 order 74 达成 RMS 0.000936916，并通过权威被动性检查。该结果说明外部工具在适当的停滞阈值下可以继续收敛，也为 Native 的适用边界提供了独立参照。

MATLAB MFT-NNLS 边界

在 S19 上，原始 MATLAB 参考工具箱即使采用更有利的无 DC 拟合和加强配置，在 order 80 以内也没有达到 RMS 0.001。因此未将该 port 作为产品路径推广。
