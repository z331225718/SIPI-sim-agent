# S 参数目标搜索导出与报告修复设计

## 背景

`fit-sparam --rms-target` 在目标搜索阶段找到符合条件的试次后，会再次执行同一阶数的拟合以写出最终文件。向量拟合在当前路径上并非严格可重复，因此第二次拟合可能比被选中的试次质量更差，导致日志、报告和导出模型不一致。

现有 HTML 报告还会将完整内部配置平铺给最终用户，且曲线依赖 Matplotlib PNG；渲染失败时只显示笼统提示，无法定位原因。

## 目标

1. 最终 SPICE、Touchstone、RFM、JSON 和 HTML 必须来自目标搜索实际选中的同一个拟合模型。
2. 报告中的 RMS 与日志选择结果一致，不允许二次拟合改变结果。
3. 最差 RMS 曲线使用无需 Matplotlib 的内嵌 SVG，并在无法生成时显示具体原因。
4. HTML 默认只显示简明的用户配置；完整配置与诊断放入折叠的“高级诊断配置”。JSON 保持完整机器可读记录。

## 设计

### 内部执行对象

新增仅供拟合流程内部使用的执行对象，持有一次拟合的公开 `SParamFitResult`、原始网络和已拟合的 vector-fit 模型。普通 `fit_touchstone_to_spice` 仍返回公开结果；目标搜索的每个试次将执行对象作为 payload 保存。

目标搜索选中试次后，不再调用拟合函数第二次。它使用该 payload 写出所有最终产物，并以同一网络与模型构造 JSON、HTML 和曲线。搜索过程仍不为未选中阶数输出产品文件。

### 报告

报告首页保留目标 RMS、最终全频 RMS、选中 order、被动性、端口数和频点数。配置表只展示搜索范围、最大步长、选中阶数、被动性策略、DC 保留和输出清单。

完整 `SParamFitConfig` 及质量诊断置于 HTML 的 `<details>` 折叠区。JSON 的 `config` 与诊断字段不删减。

### 曲线

使用内嵌 SVG 绘制曲线。每个 S 参数元素使用一张双面板图：上半部分将原始幅值和拟合幅值叠加在同一坐标系，下半部分单独绘制绝对误差。两个面板共享频率横轴，并各自显示带数值刻度的纵轴。频率全为正时采用对数横轴，否则采用线性横轴。任一轨迹不可用时，报告显示该轨迹不可用的明确原因；不会因为 Matplotlib 缺失而丢失所有图。

### RFM 文案

RFM 是通用交付格式。面向最终用户的报告和文档统一使用“RFM”和“RFM 包装网表”，不再将其称为“Cadence RFM”。文件扩展名、RFM 写出逻辑和包装网表功能保持不变。

## 验证

1. 构造非确定性假模型：首个 order 试次通过，重复拟合会失败；断言最终导出与报告仍使用首个通过模型。
2. 验证 HTML 包含内嵌 SVG、最差 RMS 元素、简明配置和折叠高级配置。
3. 验证无效曲线数据时 HTML 展示具体原因。
4. 运行既有 S 参数拟合、目标搜索及 CLI 测试。

## 范围外

不更改拟合数学、目标判定规则或 passivity 策略；不重新引入每个 order 的过程产物。
